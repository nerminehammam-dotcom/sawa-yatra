## 2. Current content model

- 71 days;
- nine sequential sections;
- 11 gate IDs representing 10 distinct place names because Puno has duplicated
  role-specific IDs;
- four sections permitting up to 16 travellers;
- ten public enquiry identifiers (complete Caravan plus nine sections);
- section-level promise, route, dates, altitude, group, feature, warnings and
  editorial arrays.

## 6. Enquiry form result

Required variables are declared in `.env.local` but all are empty:

- `RESEND_API_KEY`
- `SAWAYATRA_FORM_RECIPIENT`
- `SAWAYATRA_FORM_SENDER`

The safest local-only checks used the clearly identified address
`codex-phase1-test@example.invalid` and did not contact an external service.

| Path | Result | Side effect |
| --- | --- | --- |
| Development server | HTTP 200, `mode=development-mock`, `sent=false`, `storedOnServer=false` | No delivery or storage. The response wording nevertheless says “sent”, which is misleading in isolation. |
| Production build | HTTP 503, `delivery-not-configured`, `sent=false`, `storedOnServer=false` | No delivery or storage. This is the correct fail-loud behaviour. |

End-to-end email delivery is therefore **not available and not verified**. A
production-equivalent preview test must wait for approved configuration.

  no analytics component or event code is present.

  configured.
- `app/sitemap.ts` currently emits all nine legacy section URLs.
- `app/_metadata.ts`, `content/site.ts` and dynamic section metadata generate
  canonicals/social metadata. Root layout supplies Organization and WebSite
  JSON-LD only; product-level TouristTrip data does not yet exist.
- `next.config.ts` holds current permanent redirects. Redirect changes must wait
  until final preview approval because 301 caches can outlive rollback.
